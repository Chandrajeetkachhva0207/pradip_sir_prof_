# Pradip Divansing Jadhav — Official Executive Portfolio

Official personal brand, venture showcase, and executive profile of **Pradip Divansing Jadhav** — Founder of Samsy Wellness Network, Samsy Uni Private Limited (Enterprise IT Solutions), Hope Multipurpose Foundation, International Athlete, and Youth Mentor.

## Overview

- **Founder & Executive Director**: Samsy Wellness Network & Samsy Uni Private Limited
- **Philanthropy**: Hope Multipurpose Foundation
- **Athletics & Honors**: O-Sport World Champion, 3rd Dan Black Belt, International Martial Arts Gold Medalist
- **Keynotes & Mentorship**: Youth empowerment, sports excellence, and digital transformation

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) (Full-stack React with SSR & Streaming)
- **Routing**: [TanStack Router](https://tanstack.com/router) (Type-safe file-based routing)
- **Styling**: Tailwind CSS & Lucide React
- **Language**: TypeScript

## Getting Started

To run locally:

```sh
npm install
npm run dev
```

The application runs on `http://localhost:8080/`.

To build for production:

```sh
npm run build
```
